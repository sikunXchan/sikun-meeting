# 部門別専門スキルの設計

更新日：2026-09-26
対象要件：AC-01〜04

## 現在の実装から確認したこと

`capabilities.ts` はモデルとツール、短い手順文を返す。Claudeの`skills`は空で、Codexには同等の手順ローダーがない。

## 変更方法

`src/core/skills/catalog.ts` が担当と工程から、同梱した1つのSKILL.mdを選ぶ。両SDKには共通の手順本文をプロンプトとして渡す。既存のツール制限は変更しない。ビルド時に手順ファイルをdistへコピーする。委託RunにはIDと版だけ保存する。

## データと外部への影響

既存Runは`appliedSkills`がなくても読める。外部接続や作業フォルダ内の任意ファイルは新たに許可しない。

## 確認する範囲

`npm test`、`npm run build`、配布物への同梱確認。実AI品質の評価は別途必要。

# 部門別専門スキルの要件

作業ID：20260926-specialist-skills
状態・更新日：実装対象として合意済み・2026-09-26
依頼の根拠：ユーザーが各専門分野にAIのスキルを持たせる案に同意し、実装を依頼した。

## 変更後にどう動くか

現在：部門別の短い確認手順とスキル名はあるが、実際の手順ファイルは読み込まれない。
変更後：相談、設計、実装、QA、セキュリティの5つの手順を同梱し、担当と工程に応じてClaude・Codexの双方に渡す。Runに適用IDと版を残す。
対象外：外部プラグインの自動インストールと、案件フォルダにある任意のスキルの自動実行。

## 受け入れ条件

| ID | 前提 | 操作・出来事 | 期待する結果 | 検証方法 |
|---|---|---|---|---|
| AC-01 | 担当と工程が一致 | AIを呼び出す | 対応する手順だけがプロンプトに入る | 単体テスト・コード確認 |
| AC-02 | 担当か工程が不一致 | AIを呼び出す | 専門手順を付けず、ツール権限も広げない | 単体テスト |
| AC-03 | 配布用ビルド | ビルドする | 5つのSKILL.mdがdistに入る | npm run build |
| AC-04 | 委託のRun | 実行する | 適用スキルのIDと版が記録される | 単体テスト・コード確認 |

# 作業一覧

作業フォルダは `YYYYMMDD-feature-name` 形式で作る。1つの変更目的を1フォルダで扱う。
`_template` は雛形であり、実行対象ではない。

| 作業ID・リンク | 目的 | 状態 | 更新日 |
|---|---|---|---|

状態は「計画中・実装中・確認待ち・完了・中止」から選ぶ。
新しいセッションでは対象の作業IDを指定する。複数作業が進行中でも、各作業の状態を別々に管理する。
完了後も作業フォルダを保持する。製品として継続する仕様は `docs/` へ反映し、過去の作業文書は必要時だけ参照する。

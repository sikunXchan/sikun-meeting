# 承認済みモックアップ A + C の実装

ユーザーが画像生成した複数案を確認し、「入口はA、作業中はC」の推奨構成を承認。v0.7.3に反映した。

- 入口は依頼内容1欄を中心に、進行中の仕事と最近の成果物を右側に配置。キャラクターは小さく表示。
- 会議・成果物・設定を直接選べるナビゲーション。完成条件、AI、作業場所、利用上限、無人運用は詳細設定に維持。
- 作業中は成果物プレビューと企画・作成・確認の担当AIを並べる。新しい依頼の入力欄は置かない。
- 自動進行が既定。企画の事前確認、一時停止、途中の確認、追加指示は任意。追加指示は実行を中断してから反映し、二重実行を防いで再開。
- 依頼の入力途中に画面を移動しても、内容・完成条件・進行モードなどの未送信設定を保持。
- プレビューは追跡済みの成果物に限定。実パスで作業フォルダー内を確認し、最大4 MB、HTMLは既存の許可リストで整形。Markdown、テキスト、画像、HTML本文に対応。Office/PDF等はファイルの場所を開く。
- 既存の会議、スマホ連携、コミュニティ、監査、成果物カルテ、KGI継続、自動再試行を保持。

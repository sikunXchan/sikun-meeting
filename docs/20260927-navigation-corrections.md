# v0.7.4：画面遷移と依頼フォームの修正

承認済みA＋Cの構成を維持し、利用者が指定した3点を修正した。画像生成で修正見本を作成した。

- 会議と設定をサイドバー内の開閉から、それぞれの専用画面へ移動するナビゲーションに変更。現在の画面を選択状態で表示。
- 会議一覧はキーボード操作可能なカードに変更。既存の会議を開く操作と新規作成を維持。
- 依頼の詳細設定を「完成条件」「AI・作業場所」「自動継続」のタブに分類。項目を2列で配置し、設定欄の高さを制限。進め方と開始ボタンを同じ操作行へ移動。
- 850px幅でも依頼と履歴の2列を維持。未送信の依頼内容、完成条件、実行エンジンは画面移動後も保持。
- 画面内ロゴは古い `assets/logo.png` から、ウィンドウ・タスクバーと同じ `dist/icon.png` の参照に変更。

## 確認

- ビルド成功、Git差分の空白チェック成功。
- 実際のElectron／IPCと隔離したデータで、会議・設定・スマホ連携画面・成果物への移動、会議作成と一覧からの再表示、タブと矢印キー操作、入力保持、新ロゴの読み込みを確認。
- 850px／1000pxで横にはみ出さず、各詳細タブの表示中にも開始ボタンが画面内にあることを確認。
- 模擬AIで依頼から納品までの自動進行、一時停止、追加指示、任意の企画確認、成果物プレビューを回帰確認。
- 実AIへの新規依頼は行っていない。スマホの実同期はこの修正の確認対象外。

既存データと以前の配布版を保持し、v0.7.4は別のインストールフォルダーへ配置する。ユーザーの既存の未コミット変更を保持。コミット・PRは作成していない。

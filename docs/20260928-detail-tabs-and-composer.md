# 依頼詳細のタブと会議操作欄（0.8.4）

利用者が「操作欄が隠れる」「担当と作業、活動記録などが縦に並びスクロールが増える」と指摘。
画像生成した、紫基調の5タブ（成果物／担当と作業／活動記録／確認結果／AI詳細）のモックアップを提示し、実装の承認を受けた。

- 依頼詳細は1つのパネルを切り替える。表示中のタブは定期更新で変えず、依頼ごとに保持する。
- 作業は担当・状態の一覧。確認担当やレビューは行を開いて表示する。開閉状態は定期更新後も保持する。
- 実行状況と任意の参加操作を右側にまとめる。直近の活動は1行にし、詳細リンクで活動記録タブへ切り替える。
- 会議の個別質問は質問欄の幅を確保し、AI選択と送信、全員への質問と反論ラウンドをそれぞれ横並びにする。
- 追加操作を開いた通常パネルは内容に応じて伸びる。拡大表示では短いウィンドウでもスクロールで全操作に到達できる。
- 木目の円卓と提供されたキャラクター素材は維持する。

検証: Electron上で4つの画面幅、通常／拡大の会議操作欄、5タブ、キーボード切り替え、履歴リンク、定期更新と入力保持を確認。既存の自動進行、追加指示、PDF・XLSX表示も検証する。

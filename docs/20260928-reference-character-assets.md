# 見本画像の採用

ユーザー提供の2枚の見本をそのまま使用する指示に基づき、既存の21分野のアイコンを置き換えた。追加の画像生成、顔や衣装の描き直し、色変更は行っていない。

- 見本のカードから背景込みの絵を切り出し、中央の正方形を160×160pxに縮小した。縦横比は維持し、役割名は既存UIのテキストで表示する。
- `src/renderer/assets/personas/`、ビルド結果、`mobile/public/personas/`に同じPNGを配置。
- IT Consultant (`default.png`)、利用者 (`chief.png`)、案内役は見本にないため既存画像を維持。
- 追加17分野とDataEngineerの別案は素材として保存。AIの役割自体は追加していない。
- 原本、39カード、背景込みの絵、アイコン、切り出し座標、ハッシュはこのタスクの `outputs/characters-reference/` に保存。

確認: ビルド成功。元の0.8.0パッケージの21画像とビルド表示情報だけを更新し、全14,316個のアーカイブ内ファイルを照合。利用者のデータとは別の検証用データで、依頼画面・会議画面の画像読み込み、描画エラーなし、39カードの読み込み、21件の表示フィルター、ソース・ビルド・スマホ版の画像一致を確認。

新しい配置先は `AppData/Local/Programs/sikun-meeting-0.8.0-reference-icons`。デスクトップのショートカットを新配置先へ更新。起動中の旧版と未保存入力は保持し、次回起動で新しい画像を使う。

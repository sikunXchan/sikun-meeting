# 0.8.0 — 承認済みパール・ライラックUI

承認されたA案を依頼・会議・成果物・設定に展開。上部4タブ、最新版のロゴ、共通の配色・部品、画面幅と高さに応じた配置へ変更した。

- 依頼は入力1欄と任意の参考資料。参考資料は案件フォルダへコピーし、各工程に相対パスを渡す。
- 成果物は一覧とプレビュー。PDF.jsによるPDF表示、ExcelJSによる表の値の表示を追加。既存の実パス検査を維持する。
- 既定のAI・モデル・進行方法・保存先を保存し、次の依頼に適用。未送信の依頼内容はタブ切り替えで保持する。
- 会議の自動進行は独立意見→討論→要約の有限の流れ。一時停止は現在の発言終了後。再起動時は明示的な再開を待つ。人の決定や議決ゲートを代行しない。
- 自動進行中の手動変更をIPCで拒否し、競合を防ぐ。
- ExcelJSのuuidを互換APIを持つ11.1.1以降へ固定し、依存監査の指摘を解消した。

検証：`npm test` 64件成功。分離したElectron環境で各画面、設定永続化、添付、依頼の自動完了と手動確認、追加指示、PDFの2ページとExcelのシート切り替え、会議の停止・再開を確認。実際のAI接続はこの検証には使用していない。

制限：プレビュー4 MB、表20シート・200行・30列。表の書式全体やPowerPointなどは対応アプリを利用する。会議のAIはClaude。

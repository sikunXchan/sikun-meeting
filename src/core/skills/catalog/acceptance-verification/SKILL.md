# 受け入れ確認

## 成果物

受け入れ条件ごとの[確認表](references/acceptance-table.md)、再現手順、修正後の再確認結果。

## 手順

1. 条件ごとに、正常系と重要な異常系を一つずつ確認する。
2. 実行した操作、得られた結果、期待結果との差を記録する。
3. 受け入れ条件ごとに pass / fail / 未検証を表で記録する。期待結果、実際の結果、実行環境、証拠の場所を付ける。
4. 問題には再現手順と影響範囲を添え、修正前後で同じ条件を照合する。

## 確認基準

説明文やコードの存在だけで合格としない。合格は証拠のある条件に限る。fail や未検証が残る場合は承認せず、再確認に必要な操作を示す。

# AIの比較と評価

## 成果物

実験コード・評価データ仕様・モデル比較。

## 手順

1. 利用目的、制約、基準方式、評価対象のデータと権利を整理する。
2. 学習と評価を分離し、品質、失敗例、遅延、費用を再現できる条件で比較する。
3. 試行条件、実行結果、ばらつき、限界を残し、プロンプトやモデルの変更前後を比較する。

## 確認基準

評価漏洩、偏ったサンプル、測定条件の不一致を点検し、模擬応答と実モデルの結果を区別する。

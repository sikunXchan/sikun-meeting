# クラウド構成と運用設計

## 成果物

構成案・IaC・費用と復旧の計画。

## 手順

1. 可用性、性能、地域、データ保管、既存環境と費用条件を確認する。
2. ネットワーク、認証、保存、監視、バックアップの境界を設計し、必要なら構成コードにする。
3. 設定の静的検証と利用可能な環境での検証を分け、復旧手順と費用の前提を残す。

## 確認基準

最小権限、外部公開範囲、単一障害点、復旧可能性と費用上限を確認する。購入・本番配備は依頼の権限を越えない。

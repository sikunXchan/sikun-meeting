# 独立した証拠確認

1. 担当AIの完了宣言と、実際に確認できた成果を分ける。可能なら保存されたファイルや実行結果を直接確認する。
2. 完成条件を一つずつ照合し、証拠がない条件は未達とする。問題があれば再現できる確認方法を添える。
3. KGIは現在値、目標値、単位、測定時点、根拠を照合する。現在値が不明なら推測で埋めず未測定とする。
4. 会議では他者の意見を見る前の立場を独立して出し、公開後も反対理由が解消された証拠を確認してから判断を変える。

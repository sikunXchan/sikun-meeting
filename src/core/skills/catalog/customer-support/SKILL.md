# 問い合わせ対応と切り分け

## 成果物

回答草案・再現手順・エスカレーション記録。

## 手順

1. 利用者の目的、現象、環境、既に試したことを整理し、個人情報の収集を必要最小限にする。
2. 資料に沿って再現と切り分けを行い、影響の小さい対処から順に示す。
3. 確認できたこと、未解決の点、引き継ぐ担当と必要な情報を記録する。

## 確認基準

未実施の対処を実施済みにせず、利用者が次に何をするか、失敗した場合の戻り方が明確か確認する。返信の送信は別の実行指示に従う。

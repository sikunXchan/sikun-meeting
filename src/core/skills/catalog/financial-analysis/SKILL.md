# 費用と収支の検討

## 成果物

費用比較・収支計画・感度分析。 [感度分析表](references/sensitivity-table.md)で前提と算式を揃える。

## 手順

1. 目的、期間、通貨、税の扱い、資金条件と入力数値の出典を揃える。
2. 初期費用と継続費用、固定費と変動費を分け、計算式と仮定を明記する。
3. 基準・上振れ・下振れの条件を比較し、損益や資金不足に影響する変数を示す。

## 確認基準

金額・単位・期間・丸めと合計を照合し、推計を実績と扱わない。投資・支払の実行は行わない。

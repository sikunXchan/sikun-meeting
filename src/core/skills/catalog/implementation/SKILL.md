# 実装と引き継ぎ

エンジニアが実装を担当するときに使う。

1. 受け入れ条件と既存コードを照合し、必要な変更箇所を絞る。
2. データ形式や公開APIを変える場合は既存利用者への影響を確認する。
3. 作業段階では変更を実装し、重要な動作を実際に検証する。会議段階では設計案と検証案を述べ、ファイルは変更しない。
4. 変更内容、実行した検証、未確認の点を分けて報告する。未実行の試験を成功としない。

# 実装と引き継ぎ

## 成果物

変更したコード、受け入れ条件に対応する検証結果、移行や引き継ぎに必要な実行手順。

## 手順

1. 受け入れ条件と既存コードを照合し、必要な変更箇所を絞る。
2. データ形式や公開APIを変える場合は既存利用者への影響を確認する。
3. 変更を実装し、主要な動作と重要な異常系を実際に検証する。
4. 移行が必要なら互換性の維持方法と復旧手順を記録し、変更内容と検証の対応を示す。

## 確認基準

変更前からある動作の回帰、異常入力、公開APIと保存データの互換性を確認する。利用者が再現できる操作・環境・期待結果を添える。

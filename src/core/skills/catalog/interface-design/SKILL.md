# 操作設計とデザイン

## 成果物

画面構成・モックアップ・デザイン仕様。

## 手順

1. 利用者の主要タスクとつまずき、既存画面、ブランド、承認済みの表現を確認する。
2. 情報の優先順位と操作経路を定め、通常・空・読込中・失敗時の状態を設計する。大規模変更はモックアップを用意し、依頼者の承認方針に従う。
3. 色、余白、文字、コンポーネントを揃え、主要画面幅とキーボード操作の確認方法を示す。

## 確認基準

見た目の統一に加え、次の操作が分かるか、入力負担、コントラスト、フォーカス、誤操作からの復帰を確認する。

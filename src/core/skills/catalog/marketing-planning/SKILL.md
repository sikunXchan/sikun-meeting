# 訴求と施策の設計

## 成果物

対象顧客別の訴求案・施策計画・測定表。

## 手順

1. 対象顧客、課題、提供価値、既存の実績と比較対象を整理する。
2. 媒体ごとの伝える内容、素材、行動導線、実施条件を具体化する。
3. 仮説ごとに指標、期間、費用、比較条件と中止基準を決める。

## 確認基準

根拠のない実績・推薦・効果を作らず、対象と訴求の整合、計測可能性、表示内容の正確さを確認する。公開・配信は別の実行指示に従う。

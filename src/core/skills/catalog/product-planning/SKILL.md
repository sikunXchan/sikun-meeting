# 製品の仕事割り当て

## 成果物

完成条件と対応した少数の仕事、担当・所管・確認者の割り当て、依存関係と優先順位。

## 手順

1. 採用された企画の目的と完成条件を軸にする。過去の提案や担当AIの希望を、新しい要求として扱わない。
2. 各仕事の成果を利用者が確認できる形で定義し、完成条件のどれに対応するかを明らかにする。必要のない会議・計画・報告だけの仕事は増やさない。
3. 担当と所管が異なる場合は所管部門の確認を残す。依存する仕事だけを順に並べ、並べる理由を説明する。

## 確認基準

各仕事の成果と完成条件が対応し、所管判断と依存関係が抜けていないか確認する。必要のない会議・計画・報告だけの仕事を増やさない。

# 要件の整理

ITコンサルタントが相談・企画を扱うときに使う。

1. 発注者が達成したい結果、利用者、現状の困りごとを分けて聞く。不明点は少数の具体的な質問にする。
2. 受け入れ条件を観察できる行動と結果で書く。KGIは測定方法、目標値、期限、現時点の値を分ける。
3. 予算、期間、利用できるデータ、承認が必要な操作を明記する。未回答は仮定として残す。
4. 企画案には最小の実施範囲、確認方法、残る判断事項を含める。実装や完了を先取りして断定しない。

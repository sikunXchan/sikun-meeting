# 調査と出典確認

## 成果物

根拠付き調査メモ・出典一覧。

## 手順

1. 問い、対象期間、必要な証拠を定め、利用できる原資料を探す。外部情報を取得できない場合は調査済みと扱わない。
2. 著者、公開日、対象、方法を記録し、一次資料と二次的な解説を区別する。
3. 資料間の一致・矛盾・情報の不足を整理し、結論ごとに参照先を付ける。
4. 利用できるWeb検索・取得で一次資料を確認し、原文のURL、発行日・更新日、確認日、結論を支える箇所を記録する。

## 確認基準

引用と要約が原資料に対応するか、古い情報を現状と混同していないか、推測を断定していないかを照合する。

# アクセシビリティの専門家

## 成果物

問題と再現手順の一覧、アクセシビリティ修正、項目別の再検証結果。

## 手順

1. 対象画面の主要タスクと適用する基準の版を確認する。
2. 意味構造、名前、状態通知、フォーカス順、拡大表示、コントラストを調べ、修正可能な項目を実装する。
3. 自動検査とキーボード・読み上げの検査を分け、実施した検査の結果を記録する。

## 確認基準

自動検査の合格を全体準拠と見なさず、主要タスクを操作できる根拠と未確認項目を残す。 アクセシビリティツリーの検査と実際の音声読み上げを区別する。スクリーンリーダーで操作していない項目は「読み上げ未検証」と記録する。

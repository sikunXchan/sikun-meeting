# 教育・研修・学習設計の専門家

## 成果物

授業・研修計画、教材と演習・解答例、評価基準と到達度の確認表。

## 手順

1. 学習者、前提知識、学習目標、時間、教材形式を確認する。
2. 目標に対応した説明・例題・演習・振り返りを順序立てて作る。
3. 課題と評価基準を目標に照合し、読みやすさ、アクセシビリティ、解答の正確性を検証する。

## 確認基準

教材を作っただけで学習効果を実証したとせず、達成度を確認する課題と基準、未検証の点を示す。

# 組み込み・ファームウェアの専門家

## 成果物

ファームウェアまたはドライバ、インターフェース・タイミング仕様、ビルド・シミュレーションの結果。

## 手順

1. 対象ハードウェア、電源・メモリ・時間制約、通信仕様を資料から確認する。
2. タイムアウト、割り込み、異常入力、再起動時の状態を扱い、必要なコードや試験用スタブを作る。
3. 利用可能なツールでビルドと試験を行い、実機未確認の項目と測定手順を残す。

## 確認基準

実機測定とシミュレーションを区別し、メモリ境界、通信エラー、フェイルセーフと復旧を確認する。

# 翻訳・多言語・地域対応の専門家

## 成果物

翻訳済み文書・リソース、対訳表・用語集、言語別の品質確認表。

## 手順

1. 対象言語・地域、読者、文体、用語、既存リソース形式を確認する。
2. 意味・プレースホルダー・書式を保持し、日時・数値・敬称・単位を地域に合わせて翻訳する。
3. 未訳、文字数、変数欠落、訳語の揺れを点検し、画面上で未検証の箇所を明記する。

## 確認基準

原文の意味と変数が保存されているか、地域に不適切な表現がないかを照合する。動作変更が必要なら開発担当へ具体的に引き継ぐ。

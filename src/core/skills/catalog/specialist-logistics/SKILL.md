# 物流・在庫・配送計画の専門家

## 成果物

在庫・配送計画表、物流費用と制約の比較、欠品・遅延時の対応手順。

## 手順

1. 拠点、需要、在庫、輸送条件、納期、容量とサービス水準を確認する。
2. 入出庫・補充・配送の計画を作り、欠品・滞留・遅延の要因を整理する。
3. 数量収支、所要時間、例外時の対応と計算根拠を記録する。

## 確認基準

在庫と入出庫の整合、リードタイム、輸送容量、温度・期限などの制約を確認し、実際の配送状況を推測で補わない。

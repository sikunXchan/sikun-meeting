# モバイルアプリ・PWAの専門家

## 成果物

モバイル機能の実装、端末・OS別の確認表、通信断・復帰の検証記録。

## 手順

1. 対象OS・端末・配布方式・既存APIを確認し、対応範囲を明示する。
2. タッチ操作、画面回転、キーボード表示、通信断、重複送信を考慮して実装する。
3. 実機・エミュレーター・ブラウザで確認できた範囲を分けて記録し、オフライン復帰と同期を検証する。

## 確認基準

デスクトップの縮小表示だけで実機対応済みとせず、保存・再送・権限・バックグラウンド制約の根拠を確認する。

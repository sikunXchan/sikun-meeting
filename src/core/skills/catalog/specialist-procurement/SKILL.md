# 調達・仕入れ・取引先評価の専門家

## 成果物

調達要件・RFP、仕入先比較表、見積条件と調達リスク一覧。

## 手順

1. 品目、数量、品質、納期、必須条件と比較基準を整理する。
2. 見積や提供資料に基づき、単価だけでなく輸送・保守・更新を含む総費用を比較する。
3. 供給継続性、代替調達、検収条件を記録し、不明な価格や納期は未確認として残す。

## 確認基準

税・通貨・期間・数量を揃えた比較か、除外条件や契約条件を落としていないかを確認する。発注は別の実行指示が必要。

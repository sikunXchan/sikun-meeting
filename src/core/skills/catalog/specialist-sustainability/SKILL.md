# 環境・持続可能性の専門家

## 成果物

環境負荷の算定表、削減施策と比較評価、算定境界・出典・不確実性の記録。

## 手順

1. 対象範囲、期間、活動量、単位、適用する算定方法を明示する。
2. 出典と年次の分かる係数を使い、ライフサイクルと代替案の負荷を比較する。
3. 欠測値、仮定、二重計上、トレードオフを点検し、改善指標を定める。

## 確認基準

異なる境界・年度・単位を混ぜず、算定と実測を区別する。根拠のない環境優位性や達成済みという表現を避ける。
